# content-audit スキル

## 目的
AdSense審査や SEO改善に向けて、`content/posts/` 全記事の品質問題を一覧化する。

## 使い方
```
/content-audit
```
引数なし。全記事を自動スキャンする。

## チェック項目

### A. 語数チェック（最重要）
- 基準: **300語以上**（日本語+韓国語混在のスペース区切り）
- frontmatter (`---...---`) は除外してカウント
- 250語未満 → 🔴 緊急
- 250〜299語 → 🟡 要対応
- 300語以上 → ✅ OK

### B. frontmatter 必須フィールド
以下が全て揃っているか確認:
- `title` — 空でないこと
- `date` — YYYY-MM-DD 形式
- `excerpt` — 空でないこと
- `categories` — 少なくとも1つ
- `thumbnail` — パスが設定されていること（実在チェックは除外）

### C. 語彙表の有無
本文に `| 韓国語 |` または `| 한국어 |` 形式の Markdown テーブルがあるか。
学習系コンテンツには語彙表が必須。

### D. カテゴリ有効値チェック
有効カテゴリ: `한국어공부`, `K-POP`, `한국문화`, `한국요리`, `한일가족`
それ以外の値があれば警告。

## 実行手順

1. `content/posts/` 内の全 `.md` ファイルを一覧取得
2. 各ファイルに対して上記 A〜D をチェック
3. 問題があるファイルを集計して報告

## 出力形式

```
## コンテンツ品質レポート (YYYY-MM-DD)

### 🔴 緊急対応 (語数 250未満)
| ファイル | 語数 | 問題 |
|---------|------|------|
| xxx.md | 120語 | 語数不足, excerpt なし |

### 🟡 要対応 (語数 250〜299)
| ファイル | 語数 | 問題 |
|---------|------|------|

### ✅ OK (300語以上)
- 合計: XX件

### 📋 frontmatter 不備
| ファイル | 欠損フィールド |
|---------|---------------|

### 合計サマリー
- 全記事: XX件
- OK: XX件
- 要対応: XX件
- 緊急: XX件
```

## 注意
- node.js スクリプトでファイルを読み込んで処理すること
- 一度に全件処理し、結果を表にまとめて提示する
