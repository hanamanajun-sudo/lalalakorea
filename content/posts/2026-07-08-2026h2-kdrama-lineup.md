きなこ：上半期もいろんなドラマがあったけど、下半期はどんな作品が始まるんだろう？

ジュン：実は続々と新作情報が入ってきてるよ。話題の「シグナル」続編から、ソ・ジソプがアクションで帰ってくる作品まで、めちゃくちゃ豪華なラインアップになってる。日本の配信状況も合わせて紹介するね！

## 2026年下半期、韓国ドラマ界の注目トピック

2026年上半期も「愛のクラス3」「レジェンド・オブ・キッチン・ソルジャー」など話題作が相次ぎましたが、下半期はさらに大きなタイトルが控えています。

特に注目したいポイント：

- **「シグナル」の実質的な続編が登場** ― ファン待望の「더 세컨드 시그널（ザ・セカンド・シグナル）」
- **OTTオリジナルの勢い加速** ― Netflix、Disney+、TVINGが大型作品を投入
- **カムバック続出** ― ソ・ジソプ、イ・ミンホ、キム・テリらトップスターの新作が目白押し

それでは、これから放送が始まる注目作品をチェックしていきましょう。

## 1. 「더 세컨드 시그널（ザ・セカンド・シグナル）」― 11月、tvN放送予定

2016年の大ヒット「シグナル」のスピンオフ的作品として、最も期待を集めているのが本作です。

| 項目 | 内容 |
|------|------|
| **放送局** | tvN（国内）／Netflixで配信予定 |
| **放送時期** | 2026年11月（予定） |
| **キャスト** | キム・ヘス、イ・ジェフン（交渉中） |
| **ジャンル** | タイムリープ・サスペンス |

前作は過去と現在を無線機でつなぐ斬新な設定と、社会派ミステリーとして高く評価されました。続編では新たな事件と、前作で描かれなかった謎が明かされるといわれています。

日本ではNetflixを通じた配信が見込まれ、日本語字幕・吹き替えでの視聴が期待できます。

## 2. 「에이전트 김 재활성화（エージェント・キム、再活性化）」― 7月放送開始

ソ・ジソプが約3年ぶりにドラマ復帰。2PMのテギョン（オク・テギョン）とのバディアクションが話題です。

| 項目 | 内容 |
|------|------|
| **放送局** | tvN |
| **放送時期** | 2026年7月〜 |
| **キャスト** | ソ・ジソプ、テギョン（2PM） |
| **ジャンル** | アクション・スリラー |

かつて国家情報院のエリートエージェントだったキムが、引退後にふとしたきっかけで再び危険な任務に巻き込まれていきます。テギョン演じる若手エージェントとの凸凹コンビが笑いと緊張感を生み出す作品。ソ・ジソプの渋いアクション、必見です。

## 3. 「100일의 기만（100日の欺瞞）」― 7月放送開始

キム・ユジョンとパク・ジニョン（GOT7）という若手実力派がタッグを組んだ潜入捜査ロマンス。

| 項目 | 内容 |
|------|------|
| **放送局** | SBS |
| **放送時期** | 2026年7月〜 |
| **キャスト** | キム・ユジョン、パク・ジニョン |
| **ジャンル** | ロマンス・サスペンス |

キム・ユジョン演じるヒロインが正体を隠して大手企業に潜入捜査。そこで出会ったパク・ジニョン演じるエリート社員との危険な恋が描かれます。すでに公開された予告映像では、2人のケミストリーに期待の声が殺到中です。

## 4. 「본에이파이드 킬러（ア・ボナ・ファイド・キラー）」― 7月放送開始

カン・ホジョンがエリート犯罪捜査チームのリーダーに扮するオフィスアクション。

| 項目 | 内容 |
|------|------|
| **放送局** | tvN |
| **放送時期** | 2026年7月〜 |
| **キャスト** | カン・ホジョン |
| **ジャンル** | アクション・コメディ |

昼は普通の会社員、夜は犯罪捜査チームという二重生活を送るエリートたちの活躍を描きます。カン・ホジョンのコミカルでありながら迫力あるアクションが魅力。「会社で頼りない同僚が実は凄腕エージェント」というギャップ設定が面白いです。

## 5. 「드림 투 유（ドリーム・トゥ・ユー）」― 7月放送開始

ファン・イヌッポとGirl's Dayのヘリが主演のファンタジーロマンス。

| 項目 | 内容 |
|------|------|
| **放送局** | MBC |
| **放送時期** | 2026年7月〜 |
| **キャスト** | ファン・イヌッポ、ヘリ |
| **ジャンル** | ファンタジー・ロマンス |

初恋の相手と再会したことで人生が一変する主人公。ファンタジー要素を交えながら、過去と現在を行き来する純愛ストーリーです。ファン・イヌッポの優しい眼差しと、ヘリの明るくも切ない演技に注目が集まっています。

## 6. 「（仮称）イ・ミンホ新作ロマコメ」― 放送時期調整中

韓国を代表するトップスター、イ・ミンホが新しいロマンティックコメディへの出演を検討中と報じられました。2026年下半期から2027年初頭の放送が見込まれています。

まだキャスティング交渉段階ですが、「相続者たち」「ザ・キング」など数々のヒット作を生んできたイ・ミンホのロマコメとなれば、日本でも大きな話題になることは間違いありません。

## 7. 「더 허즈밴드（ザ・ハズバンド）」― 放送開始

ナムグン・ミンが主演を務めるヒューマンドラマ。ポスター撮影の様子も公開され、放送が目前です。

| 項目 | 内容 |
|------|------|
| **放送局** | MBC |
| **放送時期** | 2026年夏〜 |
| **キャスト** | ナムグン・ミン、イ・ソル、キム・デミョン、イ・サンヒ |
| **ジャンル** | ヒューマン・ドラマ |

「旦那」という視点から現代の家族や人間関係を描きます。ナムグン・ミンならではの重厚な演技が期待されます。イ・ソル、キム・デミョン、イ・サンヒという演技派揃いのキャスティングも見どころです。

## 8. 「（仮称）キム・テリ新作」― 出演交渉中

「二十五、二十一」「悪鬼」で存在感を示したキム・テリが新しいドラマへの出演を検討中です。具体的な作品詳細はまだ公表されていませんが、彼女の次回作というだけで注目度は抜群です。

キム・テリは出演作ごとに新たなキャラクター像を見せてくれる役者。時代劇からスリラー、ロマンスまで幅広いジャンルをこなす彼女の新境地に期待です。

## 9. 「마이 아이돌, 마이 데뷔（マイ・アイドル、マイ・デビュー）」― 放送開始

新人アイドルのデビューを描く青春ドラマ。予告編も公開され、みずみずしい演技と楽曲が話題です。

| 項目 | 内容 |
|------|------|
| **放送局** | tvN |
| **放送時期** | 2026年夏〜 |
| **ジャンル** | 青春・アイドル |

K-POPオーディション番組の裏側や練習生たちのリアルな日常を描いた作品。日本の「プロデュース101」ファンにも刺さる内容です。

## 日本で視聴する方法

これらの韓国ドラマは、以下のプラットフォームで日本語対応が期待されます：

| プラットフォーム | 主な対応作品（予定） | 日本語対応 |
|:--------------|:------------------|:---------:|
| **Netflix** | ザ・セカンド・シグナル、その他tvN作品 | 字幕・吹替 |
| **Disney+** | 一部オリジナル作品 | 字幕・吹替 |
| **Amazon Prime Video** | 新韓国ドラマも順次追加 | 字幕中心 |

日本のK-dramaファンにとって嬉しいのは、NetflixやDisney+が韓国ドラマの配信に非常に積極的になっていること。ほとんどの新作は放送と同時か、遅くとも数週間以内に日本でも配信される傾向です。

## 番外編：まだ間に合う！上半期の注目作もチェック

下半期を待ちきれない方には、まだ視聴可能な上半期の人気作もおすすめです。

- **「사랑의 클래스 3（ラブ・クラス3）」** ― K-POP業界をリアルに描いた青春ドラマ
- **「레전드 오브 키친 솔져（レジェンド・オブ・キッチン・ソルジャー）」** ― 料理×軍隊の異色作
- **「닥터 온 디 엣ジ（ドクター・オン・ジ・エッジ）」** ― 医療サスペンス

これらの作品は各配信プラットフォームで視聴可能です。

## まとめ

2026年下半期は韓国ドラマの大豊作シーズンになりそうです。「シグナル」の系譜を継ぐ作品から、ソ・ジソプのカムバック、イ・ミンホやキム・テリの新作まで、どの作品も見逃せないものばかり。

日本での配信情報は随時更新されますので、各プラットフォームの最新情報をチェックしてみてください。この秋は韓国ドラマ三昧の日々がやってきそうです！
