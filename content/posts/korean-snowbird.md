## 雪〇〇〇専用の道具が人気で品薄に！

去年の冬が終わったあと、ネット上で雪アヒルの写真がカワイイと話題になっていた韓国。

今年こそは自分も作ろう！と意気込んでいていた人たちが雪アヒルの写真や動画を一気にアップ。

それを見て知った人がさらに興味を持って…と韓国では雪アヒルがブームに。

この雪アヒル、専用の道具の雪アヒルメーカーで簡単に作れてすごくカワイイ★

元々そんなに出回っていなかった雪アヒルメーカーが一気に欠品状態になり、お値段も高騰中だとか。。

## BTSのRMも雪アヒルをtwitterに投稿！

話題の雪アヒル、BTSのRMもTwitterに投稿！

アップされた写真には、7羽のアヒルの形をした雪だるまが並んでいます。７羽の雪アヒルはBTSのメンバーたち☆

「DTS」はアヒルを意味する英語単語である“DUCK”の頭文字と、BTSを組み合わせた言葉のようです。

## 韓国語で「冬」「雪」に関する単語

今回の雪アヒルの話題にちなんで、冬・雪に関する韓国語を覚えてみましょう！

| 韓国語  | 読み方   | 意味   |
| ---- | ----- | ---- |
| 겨울   | キョウル  | 冬    |
| 눈    | ヌン    | 雪    |
| 눈사람  | ヌンサラム | 雪だるま |
| 눈오리  | ヌノリ   | 雪アヒル |
| 눈싸움  | ヌンサウム | 雪合戦  |

| 춥다   | チュプダ  | 寒い   |
| 따뜻하다 | タトゥタダ | 温かい  |

| 목도리  | モクトリ  | マフラー |

## まとめ：韓国の雪アヒルブームと韓国語

今回は韓国で流行した**雪アヒル（눈오리）**と、BTSのRMが作ったDTSについてご紹介しました。

韓国では季節ごとにさまざまなトレンドが生まれ、SNSで一気に広まる文化があります。BTSのような人気アーティストが参加することで、さらに話題が加速するのも韓国エンタメの面白いところですね！

冬の韓国語表現も覚えて、ドラマや韓国のSNSをもっと楽しんでみてください。
