## 母音は「たった10個」

まずは基本の母音から。

「たくさんありそう…」と思うかもしれませんが、**基本の母音はたった10個だけ**。
しかも、規則があるので見た目より簡単に覚えられます。

## 基本母音10個の一覧

| 母音 | 発音 | 覚え方 |
|------|------|--------|
| ㅏ | ア | 棒の右に線1本 |
| ㅑ | ヤ | 棒の右に線2本（ヤ行になる） |
| ㅓ | オ | 棒の左に線1本 |
| ㅕ | ヨ | 棒の左に線2本 |
| ㅗ | オ | 上に線1本 |
| ㅛ | ヨ | 上に線2本 |
| ㅜ | ウ | 下に線1本 |
| ㅠ | ユ | 下に線2本 |
| ㅡ | ウ | 横棒（口を横に引いて「ウ」） |
| ㅣ | イ | 縦棒 |

## コツ①：線が2本になると「ヤ行」

よく見てください。

- **ㅏ（ア）** → 線を1本足すと **ㅑ（ヤ）**
- **ㅓ（オ）** → 線を1本足すと **ㅕ（ヨ）**
- **ㅗ（オ）** → 線を1本足すと **ㅛ（ヨ）**
- **ㅜ（ウ）** → 線を1本足すと **ㅠ（ユ）**

**線が2本になると「ヤ・ヨ・ユ」のようにY音がつく**。これ、覚えておくとすごく楽です！

## コツ②：「オ」と「ウ」が2つずつある

日本語にはない区別ですが、韓国語には…

- 「オ」の音が **ㅓ** と **ㅗ** の2種類
- 「ウ」の音が **ㅜ** と **ㅡ** の2種類

あります。最初は同じに聞こえてOK。ハル（妻）も未だにたまに間違えます（笑）。
まずは「形」と「だいたいの音」をおぼえましょう。

## 単体で書くときは「ㅇ」をつける

母音だけを書くときは、前に **ㅇ**（音のない子音）をつけます。

- 아（ア） 야（ヤ） 어（オ） 여（ヨ） 오（オ）
- 요（ヨ） 우（ウ） 유（ユ） 으（ウ） 이（イ）

「あいうえお」みたいに声に出して読んでみてください。
それではクイズで確認しましょう！
