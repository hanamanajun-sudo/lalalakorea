## 「パ」が2種類ある？

韓国語には、日本語にない音の区別があります。それが**激音（げきおん）**と**濃音（のうおん）**。

同じ「パ」でも、実は韓国語では**3種類**あるんです。

- **바（パ）** … ふつうの音（平音）
- **파（パッ！）** … 息を強く出す（激音）
- **빠（ッパ）** … のどを詰める（濃音）

最初は「同じに聞こえる…」で大丈夫。ハル（妻）も未だに聞き分けが怪しいです（笑）。まずは**形**をおぼえましょう。

## 激音：線を1本足す

平音に**線を1本足す**と激音になります。息を「ハッ」と強く出すイメージ。

| 平音 | → | 激音 | 音 |
|------|---|------|-----|
| ㄱ（カ） | → | **ㅋ** | カッ（強い） |
| ㄷ（タ） | → | **ㅌ** | タッ（強い） |
| ㅂ（パ） | → | **ㅍ** | パッ（強い） |
| ㅈ（チャ） | → | **ㅊ** | チャッ（強い） |

**覚え方：** ㄱに線が増えて → ㅋ。形がヒントになっています。

## 濃音：同じ子音を2つ重ねる

平音を**2つ重ねる**と濃音。小さい「っ」を入れて、のどを詰めて発音します。

| 平音 | → | 濃音 | 音 |
|------|---|------|-----|
| ㄱ | → | **ㄲ** | ッカ |
| ㄷ | → | **ㄸ** | ッタ |
| ㅂ | → | **ㅃ** | ッパ |
| ㅅ | → | **ㅆ** | ッサ |
| ㅈ | → | **ㅉ** | ッチャ |

## K-POPで見てみよう

- EXOの **카이（カイ）** … 카＝ㅋ（激音）
- **오빠（オッパ）**＝お兄さん … 빠＝ㅃ（濃音）
- **찌개（チゲ）**＝鍋料理 … 찌＝ㅉ（濃音）

「오빠（オッパ）」はK-POPファンなら絶対知ってる単語ですよね。あの「ッ」が濃音です！

音の聞き分けは後からついてきます。今は「線1本＝激音」「2つ重ね＝濃音」の形だけ、クイズで確認しましょう👇
