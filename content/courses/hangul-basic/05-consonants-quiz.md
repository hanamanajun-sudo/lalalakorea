## 子音、定着させよう

基本子音10個の復習クイズです。5問チャレンジ！

## もう一度おさらい

| 子音 | 音 | | 子音 | 音 |
|------|-----|---|------|-----|
| ㄱ | カ行 | | ㅂ | パ行 |
| ㄴ | ナ行 | | ㅅ | サ行 |
| ㄷ | タ行 | | ㅇ | 無音 |
| ㄹ | ラ行 | | ㅈ | チャ行 |
| ㅁ | マ行 | | ㅎ | ハ行 |

**思い出すキーワード：**

- **ㅁ** は「口（くち）」の形＝マ行
- **ㅇ** は頭では音なし
- 順番は **가나다라（カ・ナ・タ・ラ）**＝韓国語の「あいうえお」

では、クイズを始めましょう 👇
