## 漢数詞の数字：1〜10

| 韓国語 | 読み方 | 意味 |
|---|---|---|
| 일 | イル | 1・一 |
| 이 | イ | 2・二 |
| 삼 | サム | 3・三 |
| 사 | サ | 4・四 |
| 오 | オ | 5・五 |
| 육 | ユク | 6・六 |
| 칠 | チル | 7・七 |
| 팔 | パル | 8・八 |
| 구 | ク | 9・九 |
| 십 | シプ | 10・十 |

## 11以上は組み合わせるだけ

漢数詞は日本語の「十・百・千・万」の感覚とまったく同じ作り方です。

- **십일**（シビル）＝10＋1＝11
- **이십**（イシプ）＝2×10＝20
- **백**（ペク）＝100
- **천**（チョン）＝1000
- **만**（マン）＝10000

「이백」（イベク）＝200、「삼천」（サムチョン）＝3000のように、日本語の「二百」「三千」とまったく同じ発想で作れます。大きな数字が出てきても、パニックにならなくて大丈夫です。

## 固有語との違いをおさらい

| | 固有語 | 漢数詞 |
|---|:---|:---|
| 使う範囲 | 1〜99 | 1〜無限大 |
| 覚え方 | 10刻みで専用の言葉 | 十・百・千・万の組み合わせ |
| 主な用途 | ものを数える | 数字そのものを読む |
