## 固有語の数字：1〜10

| 韓国語 | 読み方 | 意味 |
|---|---|---|
| 하나 | ハナ | 1・ひとつ |
| 둘 | トゥル | 2・ふたつ |
| 셋 | セッ | 3・みっつ |
| 넷 | ネッ | 4・よっつ |
| 다섯 | タソッ | 5・いつつ |
| 여섯 | ヨソッ | 6・むっつ |
| 일곱 | イルゴプ | 7・ななつ |
| 여덟 | ヨドル | 8・やっつ |
| 아홉 | アホプ | 9・ここのつ |
| 열 | ヨル | 10・とお |

## 11〜19：열＋数字

11以上は「열（10）＋数字」の組み合わせです。

- **열하나**（ヨルハナ）＝11
- **열둘**（ヨルトゥル）＝12
- **열셋**（ヨルセッ）＝13

10の位から順に並べるだけなので、1〜10さえ覚えれば作れます。

## 20・30…：10ごとの専用の言葉

20以上は、日本語の「はたち」のような専用の呼び名が10刻みで登場します。

| 韓国語 | 読み方 | 数字 |
|---|---|---|
| 스물 | スムル | 20 |
| 서른 | ソルン | 30 |
| 마흔 | マフン | 40 |
| 쉰 | スィン | 50 |
| 예순 | イェスン | 60 |
| 일흔 | イルン | 70 |
| 여든 | ヨドゥン | 80 |
| 아흔 | アフン | 90 |

「스물다섯」（スムルタソッ）＝20＋5＝25、のように組み合わせて数を作れます。

固有語の数字が使えるのは**99まで**。100以上になると漢数詞の出番です。
