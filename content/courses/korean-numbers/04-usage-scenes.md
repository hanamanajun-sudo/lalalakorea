## 場面別の早見表

| 場面 | 使う数字 | 例 |
|:---|:---|:---|
| 時間（時） | 固有語 | 한 시（ハンシ）＝1時 |
| 時間（分） | 漢数詞 | 오 분（オブン）＝5分 |
| 値段 | 漢数詞 | 만 원（マヌォン）＝1万ウォン |
| 日付 | 漢数詞 | 팔월 십사일（パルォル シプサイル）＝8月14日 |
| 年齢 | 固有語が自然 | 스물다섯 살（スムルダソッサル）＝25歳 |
| 階数 | 漢数詞 | 삼 층（サムチュン）＝3階 |
| 電話番号 | 漢数詞 | 일공일（イルゴンイル）＝101 |
| ものを数える | 固有語 | 사과 세 개（サグァ セゲ）＝りんご3個 |

## 最重要ポイント：「時」は固有語、「分」は漢数詞

ひとつの文の中で両方の数字が登場する、一番混乱しやすいパターンです。

- **세 시 십오 분**（セシ シボブン）＝3時15分
  - 세 시（3時）→ 固有語
  - 십오 분（15分）→ 漢数詞

最初は混乱しますが、慣れると自然に切り替えられるようになります。

## 日付の例外：6月・10月

日付は漢数詞ですが、月の言い方に2つだけ例外があります。

- 6月：❌ 육월 → ⭕ **유월**（ユォル）
- 10月：❌ 십월 → ⭕ **시월**（シウォル）

韓国人もこの2つは特別な読み方をするので、そのまま覚えてしまいましょう。

## 年齢の2つの言い方

- 「살（サル）」を使うとき → 固有語：**스물다섯 살**（25歳）※日常会話で自然
- 「세（セ）」を使うとき → 漢数詞：**이십오 세**（25歳）※書類やフォーマルな場面

## 電話番号の「0」

電話番号は漢数詞で1桁ずつ読みますが、「0」だけは特別です。

- 日常の数字の0 → **영**（ヨン）
- 電話番号の0 → **공**（コン）がよく使われる

「010」は**공일공**（コンイルゴン）と読みます。
