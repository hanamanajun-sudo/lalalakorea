## ここまでのおさらい

**怒りのフレーズ**

| 韓国語 | 読み方 | 意味 |
|---|---|---|
| 화나 | ファナ | 怒ってる |
| 열받아 | ヨルバダ | むかつく |
| 미쳤어? | ミチョッソ | 正気か？ |
| 뭐라고? | ムォラゴ | 何て言った？ |
| 그만해 | クマンヘ | やめろ |
| 진정해 | チンジョンヘ | 落ち着け |

**甘えのフレーズ**

| 韓国語 | 読み方 | 意味 |
|---|---|---|
| 안아줘 | アナジョ | 抱きしめて |
| 뽀뽀 | ポッポ | チュッ・軽いキス |
| 잘 자 | チャル ジャ | おやすみ |
| 내 거야 | ネ ゴヤ | 私のものよ |
| 해줘 | ヘジョ | 〜してよ |
| 삐졌어? | ピジョッソ | すねたの？ |

**言い方の3ルール**

1. 怒りは**短く、強く**
2. 甘えは**語尾を伸ばす**
3. どちらも**パンマルが基本**

## 修了したら…

8問中6問正解できたら、あなたはもう**ドラマの感情表現マスター**！

次にドラマを見るときは、ケンカのシーンとラブラブのシーンで耳をすませてみてください。字幕には出てこない「語尾の長さ」まで聞き取れたら、韓国語がぐっと立体的に感じられるはずです。

覚えた単語は、**단어 복습（単語復習）** で忘れないうちにおさらいを。

敬語とパンマルの切り替えをもっと知りたくなったら、「[敬語・タメ口の切り替えを使いこなす](/learn/polite-switching)」のコースへ。ドラマのセリフがなぜタメ口なのか、その理由まで分かるようになります。

드라마 보면서 화이팅！（ドラマを見ながらがんばろう！）💢
